# DesktopAgent
[![Unity Version](https://img.shields.io/badge/Unity-6000.0%2B-blueviolet?logo=unity)](https://unity.com/releases/editor/archive)

DesktopAgent は、デスクトップ上に 3D キャラクターを表示し、LLM を通じて作業をサポートできるアプリケーションです。

利用者は、自分好みのキャラクターモデル、音声モデル、LLM エージェントを用意して組み合わせることができます。

会話方法はテキスト入力と音声入力の両方に対応しており、フロントエンドは Unity、バックエンドは Ollama + Coeiroink を想定しています。

## 概要

- デスクトップ上に表示される AI コンパニオンアプリ
- 3D キャラクターとの会話、作業支援、状態表示を一体化
- 将来的に複数キャラクターやマルチエージェント構成へ拡張予定

## アーキテクチャ（プロセス分割）

### 方針

- 機能ごとにプロセスを分離
- プロセス間は IPC で連携

### プロセス一覧

- メイン（UI）プロセス
	- UI 表示と中央制御を担当
	- メインディスプレイでフルスクリーン表示
- キャラクタープロセス
	- キャラクター表示を担当
	- キャラクター 1 体につき 1 プロセス
	- キャラクターごとに別エージェントを割り当て可能
- 壁紙プロセス
	- 各ディスプレイの壁紙レイヤーに展開

## 主な機能

### モデル・アニメーション

- VRM / GLB / GLTF / FBX 形式への対応を予定しています。
- 現状で正式に対応しているのは VRM のみです。
- モデルは StreamingAssets フォルダに配置することで読み込めます。
- VRM 以外の形式ではアニメーションは利用できません。
- アニメーションはヒューマノイドボーンを持つモデルのみに対応しています。
- 別形状のモデルをアニメーションさせる場合は、別途アニメーションツリーの作成が必要です。

### AI チャット

- LangGraph の利用を想定しています。
- 今後は、API を用いた従量課金制のモデルと直接やり取りできる構成にも対応予定です。
- DesktopAgent とのやり取りには FastAPI を利用しています。
- API 仕様が確定した後は、詳細ドキュメントを公開し、LangGraph 以外のマルチエージェントアーキテクチャとも連携できるようにする予定です。

### TTS・STT

- キャラクターとのやり取りは、テキスト入力と音声入力の両方に対応しています。
- Text-to-Speech には Coeiroink を使用します。
- Coeiroink エンジンは本アプリとは別にインストールが必要です。
- 設定ファイルからホスト、ポート、スピーカー ID、スタイル ID を指定することで、Coeiroink 側で実装されている音声を利用できます。
- AI の返答は音声だけでなく、キャラクター横の吹き出しにもテキスト表示されます。
- Speech-to-Text には Whisper のローカルモデルを内蔵しています。
- プッシュトゥトークと常時録音に対応しています。
- 入力内容は、推論確定時に画面下へ UI 表示されます。
- マイクアイコンは録音状態を表します。
- 録音可能なときは通常アイコン、録音を拒否しているときは無効化アイコンが表示されます。
- プッシュトゥトーク時は、キー押下中のみアイコンが表示されます。

## 設定ファイル

- 設定は JSON 形式で保存されます。
- 保存先は `Application.persistentDataPath/Settings/application_settings.json` です。
- メニューの設定ファイルオープンは、実際の保存先パスを優先して開きます。

### メニューダイアログ

- キャラクターを右クリックするとメニューダイアログを開けます。
- 今後、以下の機能を実装予定です。
  - 設定一覧
  - テキスト AI チャット
  - モデルのインポート・変更
  - タスク管理・アラーム機能

## キャラクターの挙動

### ユーザー操作

- キャラクターはマウスドラッグで移動できます。
- 右クリックで対象キャラクターの設定ダイアログを UI プロセス側に表示します。
- キャラクター上でマウスホイールを操作すると拡大縮小できます。
- AI の応答はキャラクター近傍の吹き出しに表示されます。

### 状態（アニメーション／行動）

- 立ち止まり
- 座り
- 寝そべり
- 歩き
- 掴まれ
- 落下

### 行動ルール

- 立ち止まり／座り／寝そべり／歩きはランダム遷移で繰り返します。
- タスクバー上ではすべての行動が可能です。
- ウィンドウ上では座りまたは寝そべりのみ可能で、時間による状態変化は行いません。
- 歩き状態はランダム距離の移動完了で遷移し、画面外に出ないようにクランプします。
- 何もない場所では、タスクバーの高さまで落下します。
- 着地点はキャラクターの中心がウィンドウ中央に来るように調整します。
- キャラクターは画面端から壁紙プロセスと出入りできます。

### 今後の拡張

- クリック時の反応追加
- AI の処理内容に応じたアニメーション制御
- 読み上げ音声と連動したリップシンク

## 実行構成

- アプリケーション実行時は、キャラクター表示と UI 表示を分けるためにプロセスを分離して実行しています。
- UI プロセスは最前面表示になるようにしています。
- ただし、他の最前面固定ウィンドウがある場合は競合して表示されないことがあります。

## 既知の問題・動作環境に関する注意

- 常時最前面かつ複数プロセスでウィンドウを表示する構成のため、環境によっては Windows の集中モード（フォーカスアシスト）の自動ルールが誤って作動し、タスクバー通知領域の表示が一時的に切り替わることがあります。
- 発生する場合は、Windows の設定 > システム > 通知 > 自動ルール にある「フルスクリーンモードでアプリを使用しているとき」などの自動ルールをオフにしてください。

## UI（メインプロセス表示要素）

- 設定ダイアログ
- 音声入力アイコン
- 検出結果表示
- テキスト入力

### ショートカット

- ショートカットキーでキャラクター指定の音声入力ができるようにする予定です。

## SDK

### キャラクター作成用 SDK

- 各種アニメーションを設定可能
- 吹き出し位置などを設定可能

### 壁紙プロセス作成用 SDK

- 壁紙側にキャラクターの出入り口を設定可能
- 壁紙側に座れる場所を設定可能
- 壁紙側に寝そべれる場所を設定可能
- ディスプレイごとに異なる壁紙設定を利用可能
